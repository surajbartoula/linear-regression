# ft_linear_regression

A simple linear regression with a single feature, used to predict the price of a car from its mileage. The model is trained with gradient descent, implemented from scratch with no library doing the regression for us.

```
estimatePrice(mileage) = θ0 + θ1 * mileage
```

## Project structure

| File            | Description                                                        |
|-----------------|--------------------------------------------------------------------|
| `train.py`      | Reads the dataset, trains the model, saves `θ0` and `θ1`           |
| `predict.py`    | Prompts for a mileage and prints the estimated price               |
| `plot.py`       | Bonus: plots the data points and the regression line               |
| `precision.py`  | Bonus: computes MSE, RMSE, MAE and R² of the model                 |
| `data.csv`      | Dataset (`km,price`)                                               |
| `thetas.json`   | Generated by `train.py`, read by `predict.py`                      |

## Requirements

- Python 3.8+
- `matplotlib` (only for `plot.py`)

```
pip install matplotlib
```

`train.py`, `predict.py` and `precision.py` use only the Python standard library.

## Usage

```
python3 train.py data.csv       # train and save thetas.json
python3 predict.py              # enter a mileage, get a price
python3 precision.py data.csv   # evaluate the model
python3 plot.py data.csv        # display data and regression line
```

Before training, `θ0` and `θ1` are both 0, so `predict.py` returns 0 for any mileage.

## How it works

### Cost function

The model minimizes the mean squared error:

```
J(θ0, θ1) = 1/(2m) * Σ (θ0 + θ1 * x_i − y_i)²
```

### Gradient descent

At each iteration, both parameters are updated simultaneously:

```
tmpθ0 = α * 1/m * Σ (estimatePrice(x_i) − y_i)
tmpθ1 = α * 1/m * Σ (estimatePrice(x_i) − y_i) * x_i

θ0 = θ0 − tmpθ0
θ1 = θ1 − tmpθ1
```

where `m` is the number of samples and `α` is the learning rate. Both temporary values are computed from the same `(θ0, θ1)` before either parameter changes.

### Normalization

Mileage values (~10⁵) are much larger than the other quantities, which makes gradient descent unstable with a single learning rate. During training, mileage is rescaled to `[0, 1]`:

```
x' = (x − x_min) / (x_max − x_min)
```

After training, the thetas are converted back to the original scale:

```
θ1 = θ1' / (x_max − x_min)
θ0 = θ0' − θ1 * x_min
```

This is only a change of variable: the resulting line is the same, and `predict.py` works directly on raw mileage.

### Precision metrics

- **MSE**: mean of squared errors
- **RMSE**: square root of MSE, in price units
- **MAE**: mean of absolute errors
- **R²**: `1 − SS_res / SS_tot`, the fraction of price variance explained by the model

## Results on the provided dataset

| Parameter | Value      |
|-----------|------------|
| `θ0`      | 8499.60    |
| `θ1`      | −0.021449  |

| Metric | Value  |
|--------|--------|
| RMSE   | 667.57 |
| MAE    | 557.84 |
| R²     | 0.733  |

These values match the exact least-squares solution, confirming that gradient descent has converged. Example: a car with 100,000 km is estimated at about 6354.70.

## Configuration

The learning rate and number of iterations are constants at the top of `train.py`:

```python
LEARNING_RATE = 0.1
ITERATIONS = 5000
```
